Vercel Go Runtime 示例

所有接口由 api/*.go 编译成 Serverless 函数，配置通过 go:embed 内嵌

GET /api —— 路由清单

GET /api/health —— 健康检查

会返回 Go 版本、内存、实例 hostname —— 多刷几次可能看到不同 hostname，这就是 Serverless

GET /api/hello —— 查询参数

POST /api/echo —— JSON 请求体

会带上 5 条 items，受环境变量 MAX_ITEMS（默认 10）限制

GET /api/config —— go:embed 配置

证明在只读文件系统上依然能可靠读到配置

点击上方按钮，响应会显示在这里…
